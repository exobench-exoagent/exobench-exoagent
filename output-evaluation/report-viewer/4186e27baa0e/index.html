Scientific Report: Exoplanet Transit Observation of KELT-16 b

Observation Summary

The exoplanet transit of KELT-16 b was observed using the MicroObservatory telescope. The dataset consists of 255 FITS images acquired on 2026-07-08 (UTC). The observations were conducted using a CCD instrument (sq46) with a V-band filter and an exposure time of 61.0 seconds per frame.

Data Reduction and Processing

The data were processed using the EXOTIC (EXOplanet Transit Interpretation Code) pipeline. Initial processing involved correcting the inits.json↗ configuration using FITS header metadata, specifically updating the observation date, observatory coordinates (Lat: 30.6799670, Long: -104.0150170), and the nominal pixel scale (0.74 arcsec/pixel).

Target star identification was initially performed via VLM analysis, but coordinates were subsequently corrected to [1198, 1206] following EXOTIC's internal plate solve verification. Limb-darkening parameters were calculated specifically for the V-band filter to ensure model accuracy. Aperture photometry was performed with an optimal aperture of 5.3 pixels and an optimal annulus of 10.07 pixels.

Transit Results

The transit fitting was performed using a Bayesian approach. The final derived parameters are as follows:

  • Mid-Transit Time: $2461229.8185 \pm 0.0013$ BJD_TDB
  • Planet-to-Star Radius Ratio ($R_p/R_*$): $0.1454 \pm 0.00095$
  • Transit Depth: $2.11 \pm 0.028 \%$
  • Orbital Inclination: $87.73^\circ \pm 1.81^\circ$
  • Transit Duration: $0.1108 \pm 0.0011$ days

Data Quality and Diagnostics

The fit demonstrates high quality, with a residual scatter of $0.97\%$. The plate solution was successfully validated, and the light curve shows a clear transit signal consistent with the expected ephemeris for KELT-16 b.
