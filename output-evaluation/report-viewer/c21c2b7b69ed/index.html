  1. Plate Solution: Astrometry.net-based plate solving was successfully applied to all 300 images, producing a WCS solution file (tmp/wcs.fits).

  2. Target/Comparison Star Selection: Target star pixel coordinates [1199, 1197] were determined from the WCS solution. Four comparison stars from the AAVSO chart were selected at approximate positions [1050, 1050], [1280, 1080], [1060, 1220], and [1240, 1200].

  3. Aperture Photometry: Optimal aperture (5.65 pixels) and annulus (19.53 pixels) were determined automatically.

  4. Detrending: Airmass correction was applied using a quadratic airmass correction function with coefficients a1 = 0.158 ± 0.054 and a2 = 1.65 ± 1.34.

  5. Transit Fitting: The ultranest MCMC sampler was used to fit the transit model to the normalized light curve.

  • Insufficient brightness or variability in the selected comparison stars
