EXOTIC measured a transit depth of 4.80 ± 2.88%, corresponding to a radius ratio of 0.219 ± 0.066. The fitted transit duration is 0.0989 ± 0.0070 days, or approximately 2.37 ± 0.17 hours. The approximate depth-to-depth-uncertainty signal-to-noise ratio is 1.67. The reported residual scatter is 9.25%. EXOTIC did not provide BIC or reduced chi-squared values in the generated summary.

Data Quality

The reduction completed successfully with return code 0. Plate solving succeeded with 29 matched sources, and the target coordinates were corrected to the WCS-derived position before photometry. The fitted depth is broadly consistent with a transit but has substantial uncertainty; the result should therefore be treated as a tentative ground-based measurement rather than a high-precision ephemeris refinement.
