Scientific Report: Transit Observation of HAT-P-19 b

Observation Summary

An exoplanet transit observation of HAT-P-19 b was conducted on 2026-07-11 using the Cecilia telescope at the Whipple Observatory (Center for Astrophysics | Harvard-Smithsonian). The observation utilized a CCD camera with 2x2 pixel binning and a "Clear" filter. The dataset consists of 54 FITS images.

Data Reduction

The data were processed using the EXOTIC transit pipeline. Aperture photometry was performed on the target star and a set of nearby comparison stars. Target and comparison star coordinates were identified using a combination of AAVSO finder charts and FITS image analysis. The target star was located at pixel coordinates [517, 117]. Three comparison stars were used, with the best performing comparison star located at [400, 432]. No calibration frames (flats, darks, or biases) were provided for this run; therefore, the reduction proceeded without these corrections. Plate solving was enabled, and a pixel scale of 5.0 arcsec/pixel was used.

Transit Results

Transit fitting was performed using a Markov Chain Monte Carlo (MCMC) approach via the UltraNest sampler. The following planetary parameters were derived:

  • Mid-Transit Time (BJD TDB): $2461228.992 \pm 0.0058$
  • Radius Ratio ($R_p/R_*$): $0.179 \pm 0.055$
  • Transit Depth: $3.2 \pm 1.96\%$
  • Orbital Inclination: $87.09 \pm 1.45^\circ$
  • Transit Duration: $0.029 \pm 0.016$ days

Data Quality and Diagnostics

The fit achieved a residual scatter of $5.15\%$. The derived parameters are generally consistent with the expected values for HAT-P-19 b. The optimal aperture was determined to be 0.99, and the optimal annulus was 3.0.
