Data Reduction

Calibration: No flat, dark, or bias frames were available; uncalibrated images were processed directly.

Plate Solution: Successfully performed on all 300 images using ASTAP/astrometry.net, producing per-image WCS solutions.

Aperture Photometry: Differential aperture photometry performed with:

  • Optimal aperture radius: 4.27 pixels
  • Optimal annulus: 10.24 pixels
  • Best comparison star: AAVSO Field Star #103 at pixel (428, 1308)

Detrending: Light curves detrended against airmass using linear correction (coefficients: a1 = 1.0093 ± 0.0041, a2 = -0.008 ± 0.023).

Transit Fitting: Full Bayesian transit model fit using ultranest sampler with priors: Period 2.539575 ± 0.000005 d, Rp/R* 0.082 ± 0.004, a/R* 4.62 ± 0.1, inclination 88.0 ± 0.5°. Limb darkening coefficients from LDTk for Johnson V filter.

Data Quality
