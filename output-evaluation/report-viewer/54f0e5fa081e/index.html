WASP-65 b Transit Observation Report

Observation Summary

The WASP-65 b field was observed on 2026-03-12 with the Exoplanet Watch 0.4-meter telescope using a CCD camera and a Sloan r filter. The dataset contains 270 FITS science images from the sq34 instrument. Each exposure was 60 seconds, with a measured cadence of approximately 63 seconds. The target was identified at pixel coordinates (1177, 1147), using the FITS plate solution, AAVSO finder chart, and visual-coordinate workflow. AAVSO comparison stars 128 and 131 were used at (724, 1033) and (1419, 719), respectively.

Data Reduction

EXOTIC v4.3.1 processed the science images without calibration frames; no flats, darks, or bias frames were present, and their directories were correctly left empty. Astrometric plate solving was successful. Photometry was performed using PSF photometry, with comparison star 128 identified as the best comparison star. The light curve was normalized and detrended against airmass using an airmass correction function. EXOTIC calculated limb-darkening parameters and uncertainties using the Sloan r band, followed by Bayesian transit-model fitting.

Transit Results

The fitted mid-transit time is BJD\(_\mathrm{TDB}\) 2461112.5977 ± 0.0015. The orbital period prior used in the reduction is 2.3114205 ± 0.00000017 days. The measured transit depth is 1.23 ± 0.15%, corresponding to a fitted radius ratio of \(R_p/R_\star = 0.1109 ± 0.0066\). The fitted transit duration is 0.11504 ± 0.00088 days, or approximately 2.76 hours. The residual scatter is 0.57%. EXOTIC did not provide an explicit signal-to-noise ratio, BIC, or reduced chi-squared value in the final output.

Data Quality

All 270 frames were successfully processed, with no reported alignment, FITS-read, low-flux, or out-of-frame flags in the plate-status output. The fitted model converged successfully, with EXOTIC reporting acceptable sampling quality. The residual scatter is moderate relative to the transit depth, and the fitted transit parameters are consistent with a detectable transit signal. A minor reduction warning indicated an initial filter-width matching issue before the Sloan r filter was supplied interactively; the final run completed successfully with the correct filter definition.
