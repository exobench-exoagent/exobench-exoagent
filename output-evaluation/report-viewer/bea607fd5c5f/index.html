Observation Summary:
The transit of exoplanet Qatar-10 b was observed on 2024-07-15 using the LCOGT node at Haleakala Observatory. The dataset consisted of 140 FITS images with an exposure time of 77.0 seconds. A "CV" (Clear/unfiltered) filter was utilized, which was subsequently reduced to the V-band sequence.

Data Reduction:
The data were processed using the EXOTIC (EXOplanet Transit Interpretation Code) pipeline. Initial target and comparison star identification was performed using VLM-assisted visual inspection of the FITS frames and AAVSO finder charts. Aperture photometry was performed with an optimal aperture of 1.47 and sky annulus of 3.01. Detrending was applied using airmass correction.

Transit Results:

The orbital inclination was determined to be 82.56 +/- 2.61 degrees, and the transit duration was 0.094 +/- 0.018 days.
