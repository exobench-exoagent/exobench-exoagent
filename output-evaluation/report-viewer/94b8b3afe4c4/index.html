Data Reduction

The data were reduced using the EXOTIC pipeline. Target and comparison stars were identified via WCS plate solving, which corrected the initial visual estimates to pixel coordinates [1213, 1190] for the target star. Aperture photometry was performed using an optimal aperture of 5.77 pixels and an annulus of 12.03 pixels. Airmass corrections were applied with coefficients $a_1 = 0.09 \pm 0.017$ and $a_2 = 2.33 \pm 1.19$.

Data Quality

The data quality for this observation run is poor. The residual scatter of the light curve fit is $19.01\%$, which is significantly higher than typical high-precision transit observations. This high noise level resulted in a poorly constrained transit duration (effectively zero within uncertainties) and a transit depth with an uncertainty almost as large as the value itself. No clear transit signal was recovered from the noise.
