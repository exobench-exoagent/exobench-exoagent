The observation was conducted as part of the LCOGT Exoplanet Watch program targeting the hot Jupiter KELT-16 b for transit photometry.

Data Reduction

Exoplanet Transit Interpretation Code (EXOTIC v4.3.1) performed the complete data reduction pipeline:

  1. Plate Solution: Astrometric plate solving was performed on all 255 frames using astromatic catalog matching, achieving successful WCS transformations for every image.

  2. Aperture Photometry: Optimal aperture radius of 5.3 pixels and sky annulus of 10.07 pixels were determined through iterative minimization of light curve scatter.

  3. Detrending: Airmass-based detrending was applied using a quadratic airmass correction function (coefficients a₁ = 1.409 ± 0.013, a₂ = -0.3262 ± 0.0064).

  4. Comparison Stars: Three comparison stars from the AAVSO chart were selected (AAVSO designations 113, 115, 117), though EXOTIC's automated comparison star selection identified no single optimal comparison star, instead combining all three in the differential photometry.

  5. Transit Fitting: A Bayesian transit model was fit using the ultranest nested sampling algorithm, with 20,933 likelihood function evaluations (ESS = 2159, well above the 400 threshold). Priors were drawn from published KELT-16 system parameters.

Data Quality

  • Fit Quality: The nested sampling converged successfully with a Bayesian evidence logZ = -128.3 ± 0.14. All quality metrics were satisfied: ESS = 2159 (>400), KL divergence = 0.46±0.07 nats (<0.50), and evidence uncertainty = 0.14 (<0.5).
  • Residual Behavior: Post-fit residual scatter was 0.97%, indicating good photometric precision.
  • Comparison Star Selection: EXOTIC's automated selection identified no single optimal comparison star (rating all three similarly), which is common for data with comparable noise levels across the comparison field.
  • No Calibration Frames: This dataset was provided without dark, bias, or flat frames; the LCOGT pipeline had already applied these corrections at the observatory level.
